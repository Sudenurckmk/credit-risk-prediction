# Credit Risk Prediction

Kaggle kredi risk verisetini kullanarak borçluların temerrüt (default) riskini tahmin eden makine öğrenmesi projesi.

## Proje İçeriği ve Dosya Yapısı

* `data/raw/credit_risk_dataset.csv`: Orijinal Kaggle kredi risk veri seti.
* `notebooks/kesif.ipynb`: Keşifsel veri analizi (EDA) ve görselleştirme çalışmaları.
* `src/`: Model eğitimi, veri ön işleme ve değerlendirme scriptleri.
* `reports/`: Model başarı grafikleri ve feature importance görselleri.
* `requirements.txt`: Proje için gerekli Python kütüphaneleri.

## Çalıştırma

Projeyi yerel ortamınızda çalıştırmak için gerekli kütüphaneleri yükleyin:

```bash
pip install -r requirements.txt
